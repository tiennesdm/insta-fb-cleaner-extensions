# InstaClean v2.0 — Instagram DM & Chat Deleter (Chrome Extension)

Yeh Chrome Extension aapke **Instagram Direct Messages (DMs)** ko automatically bulk mein delete ya unsend karne ke liye ready hai.

## ✨ v2.0 Mein Sabhi Gaps Fix Kiye Gaye Hain
1. **🛡️ On-Page Visual Chat Protection (`🛡️ Keep / 🗑️ Clean`)**: Ab aapko usernames yaad karke type karne ki zaroorat nahi! Instagram Inbox mein har chat ke aage **`🗑️ Clean` / `🛡️ Keep`** button dikhta hai—jis chat ko bachaana ho us par click kar dein, wo green (`🛡️ Keep`) ho jayegi!
2. **📐 Container-Relative Message Detection**: Agar right side mein Conversation Info drawer khula bhi ho, tab bhi aapke sent messages accurately detect aur unsend hote hain.
3. **⚡ Background Tab Support**: Agar aap deletion chalu karke Chrome mein doosre tab par kaam karne lagte hain, tab bhi extension bina freeze huye background tab mein chalta rahega.
4. **🔄 Virtualized Scroll Memory**: Instagram ke infinite scroll par chats ya messages dubara repeat/stuck nahi honge.
5. **📂 Primary, General & Message Requests + Group Chats**: Primary ke baad automatically **General** aur **Message Requests** tabs ko bhi clean kar sakta hai, aur **Group Chats** ko skip ya leave+delete karne ka option hai.
6. **⏳ Auto Rate-Limit Cooldown**: Har 20 deletions ke baad automatic 25-second safety pause leta hai aur Instagram ke `"Try Again Later"` popup ko detect karke account ko action-block se bachata hai.
7. **⏸️ Pause / Resume & ⬇ Export Backup**: Kabhi bhi Pause/Resume karein aur delete kiye gaye items ka `.txt` backup download karein!

---

## 🚀 Chrome Mein Kaise Load / Reload Karein

1. Chrome mein `chrome://extensions/` kholein.
2. Top-right corner mein **Developer mode** ko **ON** karein.
3. Agar pehle se load kiya hai to **Reload (`↻`)** icon dabayein, warna **Load unpacked** par click karke yeh folder chunein:
   `/Users/shubhammehta/Downloads/instaextension`
4. Ab `https://www.instagram.com/direct/inbox/` open karein (ya refresh karein).
5. Jin chats ko delete nahi karna unke aage **🛡️ Keep** click karein, aur **▶ Start** dabayein!
